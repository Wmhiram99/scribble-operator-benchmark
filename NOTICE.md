# Code provenance and reuse

The operator scripts are selected experiment-code copies from the TreeEnergyLoss research workspace. `PROVENANCE.csv` records the source path of each copy. Workstation-specific path defaults were changed to relative paths or environment variables. The operator logic was otherwise retained.

No open-source license has been assigned to these operator scripts. Unless and until a license is added by the rights holder, no permission to reuse, modify, or redistribute the code is granted by this repository. Public visibility does not change that status. Confirm authorship and any upstream dependencies before choosing a license.

Dataset rights are separate from code rights. The VOC2012 and Cityscapes datasets are not included. Cityscapes data, modified versions, scribble masks, and other potentially reconstructable derivatives must not be redistributed unless the current Cityscapes terms explicitly permit it.
